# THE WIRE — 25 November 2026

A single-page world-news edition for [make.fun's news-image-20261125 competition](https://make.fun/bounty/news-image-20261125). The poster is generated deterministically with Python's standard library, a hand-defined 5×7 bitmap alphabet, and a small PNG encoder. Each of the 21 items carries a region tag, a headline, its cited source, and the report date used for its date check.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/wire-out python3 -P -s main.py
```

The program writes `entry.png` in the selected directory. With no environment variable, it writes to `out/entry.png`.

## Edition notes

The reporting dates and source attributions follow `facts.md`. The edition date is Wednesday, 25 November 2026. The image is 1024×1024 pixels and uses no network access or third-party packages.
